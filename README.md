# How to Gear — A Kingshot Forging Codex

A modern, single-page redesign of a community **Kingshot** gearing guide: forging
priority, imbuement, the "three gear sets only" rule, reforging, gear stats, per-troop
upgrade orders, governor set bonuses, and charm math.

**Live page:** https://texnottexas.github.io/kingshot-gear-guide/
